# MVP 훈련 콘텐츠 검토

## 검토 범위

- 대상: 초기 훈련 콘텐츠 18개
- 확인 항목: 목표 문장, 조사, 용언 활용, 선택지, 완성형
- 이미지·콘텐츠 ID·게시 상태는 유지한다.
- 본 검토는 언어 형식과 앱 데이터 일관성에 대한 개발 검토이며 임상적 타당성 평가는 별도로 진행한다.

## 발견한 공통 문제

1. 화면이 `base`와 선택값을 단순히 띄어 출력하여 `계산하 해요`, `걷 어요`처럼 보였다.
2. `타요`, `사요`, `만나요`의 정답 요소는 `요`인데 공통 선택지에 `요`가 없었다.
3. 선택지가 문자열이라 환자가 선택 결과를 미리 확인하기 어려웠다.
4. 불규칙 활용과 축약형은 `base + answer`만으로 완성형을 만들 수 없다.

## 적용 원칙

- 선택지는 `{ value, preview }` 형태로 저장한다.
- 정답 판정은 `value`, 화면의 완성 예시는 `preview`를 사용한다.
- 정답 선택 후에는 저장된 `completed`를 최종 결과로 표시한다.
- 용언은 `dictionaryForm + 선택 요소 → completed` 형태로 설명한다.
- 조사 문제는 `base + 조사 → completed` 형태로 설명한다.
